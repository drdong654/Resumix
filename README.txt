КОНСТРУКТОР ТЕХНИЧЕСКОГО РЕЗЮМЕ — ZIP EXPORT

Новая логика:
1. Кандидат заполняет контакты, профессиональное резюме, повторяемые блоки опыта, навыки и образование.
2. Нажимает одну кнопку «Скачать резюме (.zip)».
3. В браузере локально создаются:
   - *_resume.md
   - *_resume.docx
   - *_resume.tex
   - resume_photo.jpg/png (если выбрано фото)
4. Оба файла помещаются в один ZIP.
5. DOCX оформляется как готовое компактное резюме: шапка, разделы, стек, обязанности и результаты.
6. После экспорта форма не очищается автоматически. Черновик удаляется только по явной кнопке «Очистить».
7. Фото необязательно и не сохраняется в локальный черновик.

Важно:
DOCX-библиотека загружается с jsDelivr CDN и выполняется в контексте страницы.
Форма не делает сетевых запросов с содержимым резюме.

LATEX-ГЕНЕРАТОР

Основной сценарий не требует командной строки: форма добавляет готовый TEX-файл
в скачиваемый ZIP. Скрипт generate_resume.py оставлен как дополнительный вариант
для автоматизации и пакетной генерации из JSON.

Пример:
python3 generate_resume.py resume_data.example.json -o output/resume.tex

Если в системе установлены XeLaTeX или latexmk с XeLaTeX:
python3 generate_resume.py resume_data.example.json -o output/resume.tex --pdf

Поле photo содержит путь к JPEG/PNG относительно JSON-файла. Если поле пустое,
шапка формируется без фотографии.

TEX-файл рассчитан на XeLaTeX. Это необходимо для стабильного отображения
кириллицы без отдельной установки T2A-шрифтов.

ПУБЛИКАЦИЯ НА GITHUB PAGES

1. Создайте новый публичный репозиторий без реальных анкет и фотографий.
2. Добавьте в него содержимое этой папки целиком, включая vendor и .nojekyll.
3. Откройте Settings → Pages.
4. В Build and deployment выберите Deploy from a branch, main и /(root).
5. После публикации включите Enforce HTTPS.

Безопасность:
- внешние JavaScript-библиотеки не используются;
- сетевые запросы запрещены Content Security Policy;
- черновик по умолчанию не сохраняется;
- пользователь может удалить данные отдельной кнопкой;
- контрольная сумма локальной DOCX-библиотеки записана в SECURITY.md.
